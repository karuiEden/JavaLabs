В исходниках: при сбое чтения Scanner сам закрывает источник, а в close() стоит пустой catch:

```java
try { ((Closeable) source).close(); }
catch (IOException ioe) { /* ignore */ }
```

1. Если закрытие бросает исключение — Scanner его ловит и игнорирует. Оно теряется бесследно: наружу не летит, нигде не сохраняется.
2. Связь с try-with-resources: TWR прикрепляет исключение из close() к основному как suppressed. Но Scanner.close() ничего наружу не бросает, поэтому подавлять нечего — getSuppressed() пуст, ошибка закрытия теряется ещё до TWR. Плюс при сбое ввода источник уже закрыт внутри, и повторный close() из TWR — no-op.
