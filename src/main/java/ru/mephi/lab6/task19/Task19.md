# Упражнение 6.19 — можно ли получить `T[]` из `ArrayList<T>`

## Условие

```java
public static <T> ArrayList<T> repeat(int n, T obj)
```

Метод без проблем создаёт `ArrayList<T>`, содержащий значения типа `T`.
Можно ли из этого списка получить массив `T[]`, не используя ни значение
`Class`, ни ссылку на конструктор? Если нет — почему?

## Ответ

Попытка написать естественно:

```java
static <T> T[] toArray(List<T> list) {
    return list.toArray(new T[0]);
}
```

не компилируется:

```
error: generic array creation
        return list.toArray(new T[0]);
                            ^
```

Это ровно ограничение из 6.6.3: `new T[...]` создать нельзя, потому что
после стирания не известно, массив какого типа должен получиться.

## А если привести тип вручную

```java
@SuppressWarnings("unchecked")
static <T> T[] toArray(List<T> list) {
    return (T[]) list.toArray();
}
```

компилируется (с подавленным предупреждением), но **работает только
наполовину**. Проверено:

```
Exception in thread "main" java.lang.ClassCastException:
  class [Ljava.lang.Object; cannot be cast to class [Ljava.lang.String;
```

Что происходит: `list.toArray()` действительно возвращает `Object[]`
(компонентный тип после стирания — `Object`), а присваивание результата
переменной типа `String[]` вставляет в байткод `checkcast`, который падает.
Тип элемента списка известен только компилятору статически; в рантайме
этой информации нет.

## Вывод

**Нет, получить `T[]` нельзя.** `ArrayList` хранит элементы в
`Object[]` внутри себя (6.6.3, примечание), и тип `T` на момент выполнения
просто не существует. Единственные способы получить настоящий `T[]`:

- передать `Class<T>` и создать массив через `java.lang.reflect.Array.newInstance`;
- передать ссылку на конструктор `IntFunction<T[]>`;
- передать готовый массив `T[]` нужного размера;
- попросить сам список: `list.toArray(new String[0])` — но это уже
  заранее известный тип, а не `T`.

Упражнение 20 как раз обходит эту проблему: `@SafeVarargs ... T... objs`
даёт массив правильного типа «бесплатно», и его можно рефлективно увеличить.
