# Упражнение 6.2 — стек на массиве

Предпочитаю `Object[]`: не нужно передавать массив-прототип, а приведение к `E` сосредоточено в `pop` и безопасно, пока в стек кладут только `E`. Вариант с `E[]` сохраняет тип массива во время выполнения, но требует прототипа и может выбросить `ArrayStoreException`, если передать массив более узкого типа, чем `E`.
