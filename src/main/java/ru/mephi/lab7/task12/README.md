# Задание 12

Вместо перестановки самих слов создаётся список их индексов. `Collections.shuffle` перемешивает индексы, после чего слова выводятся в соответствующем порядке.

Перед перемешиванием конечный знак предложения сохраняется отдельно, а начальная буква исходного первого слова переводится в нижний регистр. После перемешивания первая буква нового первого слова переводится в верхний регистр, а сохранённый знак добавляется в конец.

Такой простой подход не распознаёт имена собственные: например, исходное первое слово `Москва` может стать `москва`, если окажется внутри предложения.
