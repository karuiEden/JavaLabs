# Задание 15

Метод принимает `IntFunction` и создаёт представление коллекции: значения не хранятся заранее, а вычисляются итератором при вызове `next()` для очередного индекса. Поэтому можно получить любое конечное число элементов, не создавая всю последовательность.

У такой коллекции нет конечного размера, поэтому `size()` и `toArray()` выбрасывают `UnsupportedOperationException`. `hasNext()` всегда возвращает `true`, так что обход необходимо ограничивать самостоятельно.

Аргумент `IntFunction` имеет тип `int`: после `Integer.MAX_VALUE` индекс переполняется и переходит к `Integer.MIN_VALUE`. Следовательно, итератор бесконечен, но индексы в нём циклически повторяются.
