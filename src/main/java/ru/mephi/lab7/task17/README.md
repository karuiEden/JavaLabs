# Задание 17

Загрязнение кучи возникает, когда в типизированную коллекцию через сырой тип попадает значение неподходящего типа. В примере метод с параметром `List` добавляет число в `List<String>`. Обычный список принимает его, а `ClassCastException` возникает позже, когда элемент читается как строка. Из-за этого место ошибки может быть далеко от её причины.

`Collections.checkedList(..., String.class)` создаёт проверяемое представление. Оно проверяет тип при добавлении и выбрасывает исключение непосредственно в вызове, который пытается записать число. Это помогает найти источник загрязнения.
