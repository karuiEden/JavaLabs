# Задание 18

Поля `EMPTY_LIST`, `EMPTY_MAP` и `EMPTY_SET` объявлены как сырые типы: в них не указаны типы элементов, ключей и значений. Поэтому присваивание, например, `Collections.EMPTY_LIST` переменной типа `List<String>` требует непроверяемого преобразования и вызывает предупреждение компилятора.

Методы `emptyList()`, `emptyMap()` и `emptySet()` обобщены. Компилятор выводит параметры типов из контекста, например в `List<String> names = Collections.emptyList()`, поэтому непроверяемое преобразование не требуется. Полученные пустые коллекции неизменяемы.
