# Задание 3

Для объединения, пересечения и разности множеств достаточно методов интерфейса `Set`:

- `addAll` добавляет в первое множество все элементы второго — получается объединение.
- `retainAll` оставляет только элементы, которые есть во втором множестве, — получается пересечение.
- `removeAll` удаляет элементы второго множества из первого — получается разность первого и второго.

Каждый из этих методов изменяет множество, на котором вызван. Чтобы сохранить исходные данные, в `Task3` сначала создаётся копия первого множества. Для разности порядок множеств важен: `A \ B` и `B \ A` могут отличаться.
