# Задание 4

Цикл `for-each` обходит список с помощью итератора. Если во время обхода удалить элемент непосредственно через `list.remove`, структура списка изменится без ведома итератора. При следующем обращении итератор может обнаружить изменение и выбросить `ConcurrentModificationException`.

В `Task4` показан безопасный вариант: удаление через `Iterator.remove()`. Этот метод согласует изменение с текущим итератором. Когда отдельный обход не нужен, также можно использовать `list.removeIf(...)`.

Название исключения не означает, что обязательно работают несколько потоков: ошибка возможна и в одном потоке. Механизм обнаружения таких изменений не является гарантией безопасности при многопоточном доступе.
