# Задание 6

Объявление `Map<String, Set<Integer>>` допустимо: интерфейс `Set` может хранить ссылки на конкретные множества, например `TreeSet`. Создать сам объект интерфейса нельзя, поэтому нужны конкретные реализации:

```java
Map<String, Set<Integer>> contents = new TreeMap<>();
contents.computeIfAbsent("Collections", key -> new TreeSet<>()).add(100);
```

Трудность возникает, например, при попытке присвоить переменной типа `Map<String, Set<Integer>>` объект типа `Map<String, TreeSet<Integer>>`: обобщённые типы Java инвариантны. Иначе в такую карту можно было бы добавить другой вид `Set`, хотя её значения объявлены как `TreeSet`.

При этом типы `Map` и `Set` не гарантируют порядок и не дают доступа к операциям отсортированных коллекций. Если оглавление должно предоставлять такие гарантии и операции, можно использовать `SortedMap<String, SortedSet<Integer>>`, создав `TreeMap` и `TreeSet`, как в `Task6`.
